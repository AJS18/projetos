Para executar os códigos sem erros, é necessário manter todos os arquivos na mesma pasta.

Instrução para usar o código trie.py:

Rodar com um compilador que suporte o Python.

Opções disponíveis:

Digitar 1 para buscar uma palavra;
Digitar 2 para buscar por prefixo;
Digitar 3 para inserir uma nova palavra no programa;
Digitar 4 para encerrar o programa.


Instrução para usar o código main.py:

Rodar com um compilador que suporte o Python.

Opções disponíveis:

Digitar 1 para buscar uma palavra;
Digitar 2 para buscar por prefixo;
Digitar 3 para listar os documentos .txt;
Digitar 4 para exibir as estatísticas das execuções e consultas;
Digitar 5 para encerrar o programa.

Em ambos programas, existe a diferenciação por acento. Então se buscar, por exemplo:
"computaçao", o programa não irá encontrar "computação".
